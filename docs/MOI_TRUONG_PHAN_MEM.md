# Môi trường phần mềm và các thư viện sử dụng

Hệ thống TeaLeafAI được xây dựng bằng Python và JavaScript, phục vụ hai nhiệm vụ chính là huấn luyện mô hình nhận diện bệnh lá chè và phát triển website cho người sử dụng. Môi trường huấn luyện sử dụng Python 3.12 cùng TensorFlow 2.21 và Keras 3.15 để xây dựng, huấn luyện và lưu mô hình MobileNetV2 theo phương pháp học chuyển giao. NumPy hỗ trợ xử lý dữ liệu dạng mảng; Pillow được sử dụng để đọc, chuẩn hóa kích thước và tăng cường ảnh. Scikit-learn cung cấp các công cụ chia dữ liệu theo nhóm và đánh giá mô hình thông qua Accuracy, Precision, Recall, F1-score và ma trận nhầm lẫn. Matplotlib được dùng để trực quan hóa quá trình huấn luyện và kết quả đánh giá. Ngoài ra, ImageHash hỗ trợ kiểm tra ảnh gần trùng, PyArrow đọc nguồn dữ liệu Parquet và Requests hỗ trợ tải các nguồn dữ liệu công khai.

Phần giao diện website sử dụng React 18 kết hợp HTML, CSS và JavaScript. Vite 6 hỗ trợ chạy ứng dụng trong quá trình phát triển và tạo bản build để triển khai. Node.js và npm được sử dụng để cài đặt, quản lý các thư viện và thực thi những lệnh phát triển dự án. Giao diện được thiết kế tương thích với máy tính và điện thoại, cho phép lựa chọn ảnh, chụp ảnh bằng camera, xem kết quả phân tích, tra cứu thư viện bệnh và quản lý lịch sử trên trình duyệt. Chức năng camera sử dụng các API của trình duyệt như MediaDevices, getUserMedia và Canvas.

Sau khi huấn luyện, mô hình Keras được chuyển sang định dạng ONNX bằng tf2onnx. ONNX Runtime Web 1.20.1 kết hợp WebAssembly thực hiện suy luận trực tiếp trong trình duyệt. Với chế độ mặc định này, ảnh được xử lý trên thiết bị của người dùng và không cần gửi đến máy chủ Python. Dự án vẫn cung cấp FastAPI và Uvicorn cho chế độ API tùy chọn khi cần tích hợp với hệ thống khác.

Mã nguồn được quản lý bằng Git và lưu trữ trên GitHub. Website được triển khai trên Vercel, hỗ trợ cập nhật tự động khi mã nguồn được đưa lên nhánh chính. Quá trình kiểm tra sử dụng unittest cho phần Python, công cụ kiểm tra tích hợp của Node.js cho các hợp đồng dữ liệu và Playwright với Chromium để kiểm tra chức năng website. Các công nghệ được lựa chọn phù hợp với việc phát triển và triển khai một ứng dụng nhận diện bệnh lá chè sử dụng các thư viện mã nguồn mở và dịch vụ lưu trữ miễn phí trong phạm vi giới hạn của nhà cung cấp.
